### 🛠 Installation & Setup

We provide Conda environment files to ensure all dependencies are installed with the correct versions.

**Prerequisites:**
* Install [Anaconda](https://www.anaconda.com/download) or [Miniconda](https://docs.conda.io/en/latest/miniconda.html).
* Clone this repository to your local machine.

**Create the environment (Windows):**
```bash
conda env create -f environment_win.yml
conda activate coin-ft
```

**Create the environment (UNIX - Linux/macOS):**
```bash
conda env create -f environment_unix.yml
conda activate coin-ft
```
